## Task 1: Built-in Decoders + Engine Nested Path Support

### 1a. Decoder engine — add `_get_nested` for dotted paths

In `app/decoder/engine.py`:

```python
def _get_nested(data: dict, key: str):
    """Resolve dotted-path keys like 'winlog.event_id' in nested dicts."""
    if "." not in key:
        return data.get(key)
    for part in key.split("."):
        if not isinstance(data, dict):
            return None
        data = data.get(part)
    return data
```

Update `_apply_fields`: replace `data.get(src_key)` with `_get_nested(data, src_key)`.

Update `_parse_timestamp`: replace `data.get(fields[ts_field])` with `_get_nested(data, fields[ts_field])`.

### 1d. windows-event.yaml

```yaml
name: windows-event
source: windows_event
type: json
fields:
  source_ip: source.ip
  user_agent: user_agent
  method: event.action
  uri: url.path
  status_code: http.response.status_code
  event_id: winlog.event_id
  computer: winlog.computer_name
  message: message

```

Wait, the timestamp for Winlogbeat is ISO 8601 in `@timestamp`. The decoder uses `timestamp_field` + `timestamp_format`. But `@timestamp` has `@` which is a valid dict key. Let me use a simple regex that extracts what we can, or handle `@timestamp` as the field name.

Actually, the JSON decoder does `data.get(fields[ts_field])`. For `@timestamp`, the field name in the JSON is literally `@timestamp`. The decoder YAML would have:
```yaml
timestamp_field: ts
fields:
  ts: "@timestamp"   # maps "ts" -> "@timestamp" JSON key
```

But `_get_nested` with `"@timestamp"` wouldn't try to split on dots because `@` isn't `"."`. Actually `"@timestamp"` doesn't contain `.`, so `_get_nested` just calls `data.get("@timestamp")`. That works!

Hmm but in the `_parse_timestamp` function:
```python
ts_str = data.get(fields[ts_field])
```

This becomes `_get_nested(data, fields[ts_field])` = `_get_nested(data, "@timestamp")` which calls `data.get("@timestamp")`. Works.

For `timestamp_format`, ISO 8601 like `2024-01-15T10:30:00.000Z` needs format `'%Y-%m-%dT%H:%M:%S.%fZ'`. But the milliseconds might vary. I'll use `'%Y-%m-%dT%H:%M:%S.%f'` with a `[:-1]` strip, or use `datetime.fromisoformat()` in a custom path.

Actually for simplicity in v0.8, I'll skip the timestamp parsing for Windows Event and AWS CloudTrail (they store to extra.@timestamp anyway). The key point is extracting the security-relevant fields.

## Task 2: Pipeline Module + Beats Endpoint

### 2a. app/ingest/pipeline.py

```python
def process_line(source: str, raw: str, strict: bool = True) -> str:
    event = decoder_engine.decode(source, raw)
    if event is None:
        if strict:
            raise HTTPException(422, "Log line could not be decoded")
        event = {
            "id": str(uuid.uuid4()),
            "source": source,
            "ingested_at": datetime.now(timezone.utc),
            "raw": raw,
        }
    duckdb_store.insert_event(event)
    try:
        chroma_store.upsert_event(event)
    except Exception as exc:
        logger.warning(f"ChromaDB upsert failed (non-fatal): {exc}")
    rule_engine.evaluate(event)
    return event["id"]
```

### 2b. Update app/ingest/router.py

- Remove `_process_line` from router; import `process_line` from pipeline
- Keep `/raw` and `/file` using `process_line(source, raw, strict=True)`
- Add `POST /ingest/beats`:

```python
@router.post("/beats")
async def ingest_beats(request: Request, _: AuthUser = Depends(require_admin)):
    if not settings.tinysiem_beats_enabled:
        raise HTTPException(503, "Beats endpoint disabled")
    body = await request.body()
    lines = body.decode("utf-8", errors="replace").splitlines()
    items, errors = [], False
    i = 0
    while i < len(lines) - 1:
        action_line = lines[i].strip(); i += 1
        if not action_line: continue
        doc_line = lines[i].strip(); i += 1
        if not doc_line: continue
        try:
            doc = json.loads(doc_line)
            source = (
                (doc.get("fields") or {}).get("source")
                or (doc.get("agent") or {}).get("type")
                or "beats"
            )
            raw = doc.get("message") or doc_line
            event_id = process_line(source, raw, strict=False)
            items.append({"index": {"_id": event_id, "result": "created"}})
        except Exception as exc:
            logger.warning(f"Beats ingest error: {exc}")
            items.append({"index": {"error": str(exc)}})
            errors = True
    return {"items": items, "errors": errors, "took": len(items)}
```

### 3b. app/listeners/syslog.py

Key functions:
- `detect_format(raw: str) -> str` — returns `"syslog_rfc5424"` if `"1 "` after priority, else `"syslog_rfc3164"`
- `_handle_line(raw: str)` — calls `process_line(detect_format(raw), raw, strict=False)`
- `_UDPProtocol(DatagramProtocol)` — `datagram_received` calls `run_in_executor(None, _handle_line, raw)`
- `_handle_tcp(reader, writer)` — readline loop calling `run_in_executor(None, _handle_line, raw)`
- `async start_syslog_listeners() -> list` — starts UDP and/or TCP server based on config; returns server objects
- `stop_syslog_listeners(servers: list)` — calls `.close()` on each
